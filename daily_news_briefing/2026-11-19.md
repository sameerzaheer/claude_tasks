# Daily News Briefing — 2026-11-19

## 🤖 AI / LLMs / AI Products

- At Ignite (Nov 17), Microsoft launched its in-house MAI Code 2 and Code 2 Flash coding models in GitHub Copilot. Microsoft says, in benchmarks it chose itself, that Code 2 matches about 96% of Claude Opus 5.5's coding performance at roughly 5% of the cost. ([The New Stack](https://thenewstack.io/microsoft-mai-code-2/))

## ⛏️ AI in Mining

- A McKinsey analysis (Nov 18) finds that pilots of autonomous haulage, fatigue monitoring and AI hazard detection have made mines safer, but that scaling them up takes sustained change management. ([International Mining](https://im-mining.com/2026/11/18/mckinsey-on-harnessing-ai-to-make-mining-safer))

## 🔍 AI in Mineral Exploration

- Earth AI's model flagged the Meridian prospect at Fontenoy, NSW, a site explorers gave up on in 1969. About 13,600 m of drilling there has now traced a copper-gold-PGM system along roughly 3 km of strike and below 478 m depth, and Earth AI is drilling toward a first JORC resource. ([MINING.COM](https://www.mining.com/ai-strikes-copper-gold-where-explorers-gave-up-in-1969/))

## 🔧 Hardware / Sensor Opportunities

- DJI's new Matrice 5T enterprise drone combines lidar, mmWave radar, vision sensors and a 1K thermal camera, and fuses them so it can fly stably where GPS is weak. *Opportunity: a mass-market drone now carries a sensor suite that used to need a custom build, so it can work underground and in other places without GPS. Lucrative uses include inspecting underground stopes and mine shafts, inspecting the inside of tanks and boilers, inspecting bridge undersides, and running thermal surveys of solar farms and substations.* ([Commercial UAV News](https://www.commercialuavnews.com/dji-launches-matrice-5t-with-lidar-mmwave-radar-and-1k-thermal-camera))
